# Política de Privacidade — FrameLab

**Última atualização:** 15/10/2026

FrameLab é uma aplicação de uso pessoal e interno que utiliza a YouTube Data API v3
exclusivamente para publicar vídeos no canal do YouTube pertencente ao próprio desenvolvedor.

## Dados coletados

A aplicação não coleta, armazena, processa ou compartilha dados de terceiros.
O único dado utilizado é o token OAuth da conta do desenvolvedor, armazenado de forma
segura e usado apenas para autenticação junto à API do YouTube.

## Uso dos dados do Google

O acesso à API do YouTube restringe-se ao escopo de upload e gerenciamento de vídeos
do canal do desenvolvedor. Nenhum dado de outros usuários é acessado.

## Serviços de terceiros

O uso da API do YouTube está sujeito aos
[Termos de Serviço do YouTube](https://www.youtube.com/t/terms) e à
[Política de Privacidade do Google](https://policies.google.com/privacy).

## Revogação

O acesso pode ser revogado a qualquer momento em
https://myaccount.google.com/permissions.
